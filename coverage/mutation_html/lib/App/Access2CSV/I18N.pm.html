  177: =head1 DESCRIPTION
  178: 
  179: Every message that App::Access2CSV prints, logs or throws is looked up
  180: here, by a short name called a I<key> (for example C<output_exists>).
  181: This keeps all the text in one place, so the program can be translated.
  182: 
  183: The text for each key is a I<template>.  A template is usually a
  184: C<sprintf> format: C<%s> is replaced by a text value and C<%d> by a whole
  185: number, in order.  A template can also have different forms:
  186: 
  187: =over 4
  188: 
  189: =item * B<Plural forms>, chosen by a count: C<one> for one item,
  190: C<other> for any other number.  Some languages use more forms
  191: (C<zero>, C<two>, C<few>, C<many>).
  192: 
  193: =item * B<Context forms>, chosen by a word you give, such as C<male> or
  194: C<female>.  A context form can itself contain plural forms.
  195: 
  196: =back
  197: 
  198: The templates live in the hash C<%App::Access2CSV::I18N::MESSAGES>:
  199: 
  200: 	%MESSAGES = (
  201: 		en => {
  202: 			missing_database => 'Missing database filename',
  203: 			summary => {
  204: 				one   => 'Processed %d table, %d failed',
  205: 				other => 'Processed %d tables, %d failed',
  206: 			},
  207: 			...
  208: 		},
  209: 	);
  210: 
  211: Only English (C<en>) is included.
  212: 
  213: =head2 Which language is used
  214: 
  215: =over 4
  216: 
  217: =item 1. The C<language> field of the object, if you call C<i18n> on an
  218: object that has one (for example
  219: C<< App::Access2CSV::Exporter->new(language => 'en') >>).
  220: 
  221: =item 2. Otherwise the first of these environment variables that is set
  222: and is not C<C> or C<POSIX>: C<LANGUAGE>, C<LC_ALL>, C<LC_MESSAGES>,
  223: C<LANG>.  Only the language part is used: C<de_DE.UTF-8> means C<de>.
  224: Upper or lower case does not matter.  C<LANGUAGE> can hold a list such as
  225: C<fr:de>; only the first entry is used.  An empty value, or an empty
  226: first entry (C<:de>), counts as "not set", so the next variable is tried.
  227: 
  228: =item 3. If there is no catalog for that language, English is used.
  229: 
  230: =back
  231: 
  232: Inside a language, a key that has no translation falls back to the
  233: English text, one key at a time.
  234: 
  235: =head2 Helpers for subclasses
  236: 
  237: Subclasses get two protected methods.  They can be called only from this
  238: class and its subclasses:
  239: 
  240: =over 4
  241: 
  242: =item * C<< $self->_croak_i18n($key, \%args) >> - throws an exception
  243: (with L<Carp/croak>) with the translated message.  It never returns.
  244: 
  245: =item * C<< $self->_carp_i18n($key, \%args) >> - warns (with
  246: L<Carp/carp>) with the translated message, with control characters
  247: escaped.  It returns C<$self>.
  248: 
  249: =item * C<< $self->_printable($text) >> - returns C<$text> with control
  250: characters (C0 except tab, DEL, C1, and text-direction controls) shown
  251: as escapes such as C<\x1B>, so that text from an untrusted database is
  252: safe to print or log.
  253: 
  254: =back
  255: 
  256: =head1 ENCODING
  257: 
  258: =over 4
  259: 
  260: =item * B<The English catalog> is plain ASCII.
  261: 
  262: =item * B<Values in params> are copied into the message as they are.
  263: Byte strings (such as UTF-8 file names from the command line) stay byte
  264: strings, so non-ASCII text and emoji come out unchanged when printed.
  265: 
  266: =item * B<Translations with non-ASCII text> (for example German C<ue>
  267: written as one letter, or Japanese) must be Perl character strings: write
  268: them in a source file with C<use utf8;>.  Do not mix them with UTF-8
  269: I<byte> strings in C<params>, or the bytes will be encoded a second time.
  270: When you print such messages, give the output handle an encoding, for
  271: example C<binmode(STDERR, ':encoding(UTF-8)')>, or Perl warns
  272: "Wide character in print".
  273: 
  274: =back
  275: 
  276: =head1 COMMON PITFALLS
  277: 
  278: =over 4
  279: 
  280: =item * B<Percent signs.>  A template with no C<params> is returned
  281: exactly as written, so C<100%> is safe.  But when you give C<params>, the
  282: template goes through C<sprintf>, so a literal percent sign must be
  283: written C<%%>.
  284: 
  285: =item * B<Number of values.>  Give exactly as many C<params> as the
  286: template has placeholders.  Too few gives a Perl "Missing argument"
  287: warning; C<undef> in C<params> gives a "Use of uninitialized value"
  288: warning.
  289: 
  290: =item * B<No count means plural.>  If you do not give C<count>, the
  291: C<other> form is used, even if the number in C<params> is 1.
  292: 
  293: =item * B<Replacing a key replaces all of its forms.>
  294: C<%MESSAGES> is not merged in depth.  If you set
  295: C<< $MESSAGES{en}{summary} = 'Done' >>, the C<one> and C<other> forms of
  296: C<summary> are gone.  If a translation gives a plural hash, it should have
  297: an C<other> form: when no form fits, the English text for that key is
  298: used instead.
  299: 
  300: =item * B<Unknown context.>  A C<context> that the template does not have
  301: is ignored; the plural forms (or the plain text) are used instead.
  302: 
  303: =item * B<Unknown keys are fatal.>  A key that is not in the English
  304: catalog is a programming error: C<i18n> calls C<confess>, which stops the
  305: program and prints a stack trace.
  306: 
  307: =item * B<undef arguments.>  C<undef> for C<args>, or for a field inside
  308: the hashref form, is treated as "not given".  C<undef> as the key is
  309: reported as a missing key.
  310: 
  311: =item * B<Load with use, not require.>  The protection of C<_croak_i18n>
  312: and C<_carp_i18n> is set up at compile time.  After a run-time
  313: C<require> it is missing, and Perl prints "Too late to run CHECK block".
  314: 
  315: =back

  319: =head2 i18n
  320: 
  321: =head3 Purpose
  322: 
  323: Turn a message key into text in the user's language.  Choose the right
  324: context and plural form, then fill in the values.
  325: 
  326: =head3 Arguments
  327: 
  328: You can call C<i18n> on the class or on an object.  There are two ways
  329: to give the arguments:
  330: 
  331: 	$obj->i18n($key, \%args);
  332: 	$obj->i18n({ key => $key, args => \%args });
  333: 
  334: =over 4
  335: 
  336: =item C<key> (string, required)
  337: 
  338: The message key, for example C<'output_exists'>.
  339: 
  340: =item C<args> (hash reference, optional)
  341: 
  342: =over 4
  343: 
  344: =item C<params> - an array reference of the values for the placeholders,
  345: in order.
  346: 
  347: =item C<count> - a whole number, 0 or more, that chooses the plural form.
  348: 
  349: =item C<context> - a word that chooses a context form, for example
  350: C<'female'>.
  351: 
  352: =back
  353: 
  354: =back
  355: 
  356: =head3 Returns
  357: 
  358: The message as a string, without a newline at the end.
  359: 
  360: =head3 Side Effects
  361: 
  362: None.  It only reads C<%MESSAGES> and C<%ENV>.  Your C<$@>, C<$!> and
  363: C<$_> are left as they were.

  405: 
  406: 	key      valid:   a key in the English catalog

  413: 	         edges:   English and German: 1 is singular, 0 and 2 plural.
  414: 	                  French: 0 and 1 singular.  Japanese, Korean,
  415: 	                  Chinese: always the "other" form
  416: 	params   any number of values, including none; each value is
  417: 	         copied into the text exactly, whether it is a Perl
  418: 	         character string or UTF-8 bytes (non-ASCII letters,
  419: 	         emoji, joined emoji, combining marks, right-to-left text)
  420: 	context  any string; one the template does not have (including "")
  421: 	         is ignored; a reference is invalid
  422: 	language (from the environment) the first 2 or 3 letters, in any
  423: 	         case; 1 letter, non-ASCII letters, C and POSIX all mean
  424: 	         "no language"

  449: =head3 PSEUDOCODE
  450: 
  451: 	check key and args
  452: 	lang := the object's language, or the language from the environment,
  453: 	        or English if there is no catalog for it
  454: 	for try in (lang, then en if lang is not en):   # at most 2 tries, no recursion
  455: 		entry := catalog[try][key], or else catalog[en][key]
  456: 		if entry has forms and one matches args.context:

  462: 	if no try gave a plain string: confess (the catalog is broken)
  463: 	if there are params: return sprintf(entry, params)
  464: 	else: return entry unchanged
